# SushiHome

Opis projektu

SushiHome to treningowa makieta strony internetowej restauracji sushi. Projekt został stworzony w celu nauki tworzenia stron internetowych oraz rozwijania umiejętności programowania i projektowania.

Strona przedstawia przykładową restaurację, jej menu oraz dostępne produkty. Została zaprojektowana tak, aby była czytelna, estetyczna i prosta w obsłudze.

Funkcje strony

Na stronie znajdują się następujące elementy:

Strona główna z krótkim opisem restauracji.

Sekcja „About Us” z informacjami o restauracji.

Menu z przykładowymi daniami sushi i ich cenami.

Sekcja z produktami.

Sekcja z opiniami klientów.

Sekcja kontaktowa.

Sekcja z wpisami na blogu.

Wyszukiwarka.

Koszyk z przykładowymi produktami.

Menu nawigacyjne umożliwiające przechodzenie między sekcjami.

Technologie

Projekt został wykonany przy użyciu następujących technologii:

HTML odpowiada za strukturę strony.

CSS odpowiada za wygląd, kolory, układ i dostosowanie strony do różnych ekranów.

JavaScript odpowiada za wybrane funkcje interaktywne, takie jak otwieranie menu, wyszukiwarki i koszyka.

Uruchomienie projektu

Aby uruchomić stronę, należy:

Pobrać lub skopiować pliki projektu.

Otworzyć folder Strona4LO.

Otworzyć plik index.html w przeglądarce internetowej.

Do podstawowego uruchomienia strony nie jest potrzebny serwer ani instalowanie dodatkowych programów.

Cel projektu

Celem projektu jest nauka tworzenia stron internetowych, ćwiczenie pracy z HTML, CSS i JavaScript oraz poznawanie zasad projektowania interfejsów użytkownika.

Uwaga: SushiHome jest makietą treningową. Przedstawione produkty, ceny i treści mają charakter przykładowy. Strona nie jest pełnym systemem restauracyjnym i nie obsługuje rzeczywistych zamówień ani płatności online.
